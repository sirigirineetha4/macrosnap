# 🥗 MacroSnap — AI Nutrition Assistant

MacroSnap is an AI-powered nutrition assistant that helps users understand the estimated calories and macronutrients in their meals. Users can describe their food through text or upload a meal photo to receive an instant nutrition breakdown.

🔗 **Live Demo:** https://macrosnapgit-vkbr5e78uyappkbxr3nabra.streamlit.app/

📂 **GitHub Repository:** (https://github.com/sirigirineetha4/macrosnap)

## ✨ Features

* **AI-Powered Nutrition Analysis:** Get estimated calories, protein, carbohydrates, and fat.
* **Meal Photo Analysis:** Upload a food image to receive a nutrition estimate.
* **Text-Based Food Queries:** Describe a meal and receive an AI-generated nutrition breakdown.
* 

## 🛠️ Technologies Used

* **Python** — Core application logic
* **Streamlit** — Web application interface
* **Google Gemini API** — AI-powered text and image analysis
* **Twilio API** — WhatsApp messaging integration

1. Enter your name and WhatsApp number.

## 📲 WhatsApp Integration Requirements

MacroSnap uses Twilio's WhatsApp Sandbox to send meal summaries to WhatsApp.

To test WhatsApp delivery:

* The recipient's WhatsApp number must join the Twilio Sandbox by sending the required join code to the sandbox number.
* The number entered in MacroSnap must match the WhatsApp number connected to the Sandbox.
* Valid Twilio credentials, including the Account SID and Auth Token, must be configured.
* The WhatsApp Content Template SID must be configured for template-based summary messages.

**Important:** Entering a WhatsApp number in MacroSnap does not automatically register it with Twilio. The recipient must complete the Sandbox joining process before testing message delivery.

The Twilio Sandbox is intended for testing. A production WhatsApp sender may require a different configuration and additional setup.

## 🚀 Run Locally

### Prerequisites

* Python 3.12 recommended
* A Google Gemini API key
* A Twilio account for WhatsApp functionality

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/sirigirineetha4/macrosnap.git
cd macrosnap
```

**2. Create and activate a virtual environment**

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

**3. Install dependencies**

```bash
python -m pip install -r requirements.txt
```

**4. Configure API credentials**

Create a `.streamlit/secrets.toml` file in your project directory and add your credentials:

```toml
GEMINI_API_KEY = "your-gemini-api-key"
TWILIO_ACCOUNT_SID = "your-twilio-account-sid"
TWILIO_AUTH_TOKEN = "your-twilio-auth-token"
TWILIO_WHATSAPP_FROM = "whatsapp:+14155238886"
TWILIO_CONTENT_SID = "your-content-template-sid"
```

Replace the placeholder values with your actual credentials. Keep these credentials private and never upload your real `secrets.toml` file to GitHub.

**5. Run the application**

```bash
python -m streamlit run app.py
```

The application will open in your browser, usually at `http://localhost:8501`.

## ☁️ Deployment

MacroSnap is deployed using Streamlit Community Cloud.

To deploy your own instance:

1. Fork or clone the GitHub repository.
2. Connect your GitHub account to Streamlit Community Cloud.
3. Select the repository, `main` branch, and `app.py` as the main file.
4. Configure the required secrets in the app's settings.
5. Deploy the application.

## 🔐 Security Notes

* Keep API keys and authentication tokens private.
* Do not commit `.streamlit/secrets.toml` to GitHub.
* Configure production credentials through Streamlit Community Cloud's Secrets settings.
* Never share your Twilio Auth Token or Gemini API key publicly.
